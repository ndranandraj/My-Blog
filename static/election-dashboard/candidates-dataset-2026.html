Methodology

How the two files were built — short version. Full code is in the parent project's pipelines/ folder.

Roster

Scraped from tnelections2026.in's public Candidates Explorer (data/candidates_bundle.min.js), cross-referenced against MyNeta's TN 2026 listings, and reconciled against the ECI's official 4,023 count. Constituencies join via constituency_no; parties resolved by short code with auto-creation for previously-unknown small parties. Asset values re-parsed from "₹X.XX Cr / L" strings into INR integers.

Dummy pairs

For every major-alliance candidate (DMK / ADMK / their formal allies), scan all other candidates in the same AC and score the name overlap after normalisation: prefixes (Mr / Shri / Selvi / Thiru) stripped, single-letter initials dropped, punctuation removed. Three tiers of match emerge — EXACT (identical post-normalisation), NEAR_FULL (≥0.85 similarity), and WORD_MATCH (one significant word ≥ 4 chars in common).

How to use it

Quick-start snippets. Drop in, modify, ignore the rest.

# Python — pandas
import pandas as pd

candidates = pd.read_csv("candidates-2026.csv")
pairs      = pd.read_csv("dummy-pairs-2026.csv")

# Top 10 wealthiest candidates with usable asset data
(candidates
   .query("assets_declared > 100_000")             # filter the ~170 ambiguous rows
   .nlargest(10, "assets_declared")
   [["candidate_name", "party_code", "constituency_name", "assets_declared"]])

# DMK constituencies with at least one EXACT-match dummy
hot = (pairs
   .query("major_alliance == 'INDIA' and category == 'EXACT'")
   .groupby("constituency")
   .size()
   .sort_values(ascending=False))
# SQL — load into Postgres or DuckDB
CREATE TABLE tn2026_candidates AS
   SELECT * FROM read_csv_auto('candidates-2026.csv');

-- candidate count by alliance
SELECT alliance, COUNT(*) FROM tn2026_candidates
 WHERE alliance IS NOT NULL
 GROUP BY alliance
 ORDER BY 2 DESC;

Caveats — read before publishing

Three known gaps. Worth knowing before you build a chart on top of any of them.

1 · Criminal-case data is missing

criminal_cases is 0 for every row. MyNeta's web pages broke against the scraper at publication time, and the ECI affidavit portal returns 403 to bot requests. The field will be backfilled when ADR releases its 2026 analysis report.

2 · ~170 asset values are still wrong

Where a constituency has multiple candidates with the same name and same party (e.g. three independents named Loganathan. M in Salem), the asset re-parser couldn't disambiguate which physical candidate to update and skipped them. Those rows hold values off by 10⁵–10⁷. Filter with assets_declared > 100000 if assets matter.

3 · One person, two seats

C. Joseph Vijay (TVK) appears in both Perambur and Tiruchirappalli (East) with different declared assets. Either he's genuinely contesting both (legal but rare) or the source data has a snapshot mismatch. Cross-reference with the official TVK list before drawing conclusions.
