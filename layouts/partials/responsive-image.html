{{- /* responsive-image.html — emit a resized, responsive for an image that lives under assets/ (so Hugo Pipes can process it). Why this exists: every published image is referenced by an absolute path like "/images/foo.jpg". Files under static are copied verbatim and CANNOT be processed by Hugo, so the old render hooks always fell through to a full-size . We now keep a processing master under assets/images/ with the same filename; this partial resolves it via resources.Get and emits resized variants (capped at 1500px) with a srcset so phones get a small file. WebP note: this intentionally does NOT generate WebP. Hugo 0.153's bundled WebP encoder OOMs the GitHub Actions runner even on modest (~3 MP) images, so WebP is best handled at the CDN edge (Cloudflare) rather than at build time. Right-sizing alone is the bulk of the performance win. Safe-by-fallback: emits a plain lazy at the original src — the previous behaviour — when there is no asset master (SVGs, external URLs), or when the asset cannot be decoded (e.g. WebP bytes mislabeled as .jpg). We probe the resize with `try` and fall back cleanly instead of failing the build. Params (dict): src (required) e.g. "/images/foo.jpg" alt alt text (default "") title optional title attribute class optional class attribute sizes default "(min-width: 768px) 720px, 100vw" loading "lazy" (default) or "eager" for above-the-fold / LCP images decoding "async" (default) fetchpriority optional, e.g. "high" for the LCP cover */ -}} {{- $src := .src -}} {{- $alt := .alt | default "" -}} {{- $title := .title -}} {{- $class := .class -}} {{- $sizes := .sizes | default "(min-width: 768px) 720px, 100vw" -}} {{- $loading := .loading | default "lazy" -}} {{- $decoding := .decoding | default "async" -}} {{- $fetchpriority := .fetchpriority -}} {{- $widths := slice 480 720 1080 1500 -}} {{- $img := "" -}} {{- if and $src (hasPrefix $src "/") -}} {{- $img = resources.Get (strings.TrimPrefix "/" $src) -}} {{- end -}} {{- /* Decide whether we can actually process this image. Guard the extension check with a real resize probe so a mislabeled/undecodable file falls back instead of erroring the build. */ -}} {{- $canProcess := false -}} {{- if and $img (in (slice "jpeg" "png") $img.MediaType.SubType) -}} {{- $probe := try ($img.Resize "480x q82") -}} {{- if not $probe.Err -}}{{- $canProcess = true -}}{{- end -}} {{- end -}} {{- if $canProcess -}} {{- /* Build the set of target widths (those <= the source width), capped at 1500px. If the source is narrower than the smallest target, just use its native width. */ -}} {{- $targets := slice -}} {{- range $w := $widths -}} {{- if ge $img.Width $w -}}{{- $targets = $targets | append $w -}}{{- end -}} {{- end -}} {{- if not $targets -}}{{- $targets = $targets | append $img.Width -}}{{- end -}} {{- $srcset := slice -}} {{- $fallback := $img.RelPermalink -}} {{- range $w := $targets -}} {{- $r := $img.Resize (printf "%dx q82" $w) -}} {{- $srcset = $srcset | append (printf "%s %dw" $r.RelPermalink $w) -}} {{- $fallback = $r.RelPermalink -}} {{- end -}} {{- else -}} {{- end -}}
