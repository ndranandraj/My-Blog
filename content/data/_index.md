Every investigation on this site that runs on original data ships the data with it. Each release below links to a public GitHub repository containing the raw and analysed files, a data dictionary, a methodology note, and the scripts used to produce the charts.

All datasets are released under the **Creative Commons Attribution 4.0 International licence (CC-BY-4.0)**. You're free to use them for reporting, research, teaching, or anything else — all I ask is a citation back to the relevant post. If you build on one of these and publish something, I'd love to hear about it.

If a dataset is useful to you and something looks wrong, noisy, or worth extending, open an issue or a pull request on the dataset's repo. Corrections are welcome.
